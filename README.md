# PixelOnWP

Enterprise-grade server-side tracking, Meta Pixel, CAPI, GTM, GA4, DataLayer, and WooCommerce tracking suite for WordPress.

## Features
- Meta Pixel & Conversions API (CAPI)
- Google Analytics 4 (GA4) & GTM DataLayer
- TikTok, Pinterest, Snapchat, LinkedIn, Reddit Pixel & CAPI Integrations
- WooCommerce Tracking Integration
- Multi-channel event routing & server-side dispatching

## Requirements
- WordPress 6.0+
- PHP 8.0+
